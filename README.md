# Decentralized Unlabeled Multi-Agent Navigation in Continuous Space

This repository contains the source code for algorithms designed for decentralized anonymous/unlabeled multi-agent pathfinding (navigation) in continious space. This is alsoa placeholder repository for supplementary materials related to the ICR 2024 conference report titled "Decentralized Unlabeled Multi-Agent Navigation in Continuous Space" The source code for the multi-agent DECentralized Unlabeled NAVigation method (DEC-UNAV) and the experimental data will be here available soon.

## Repository Structure

The repository is organized into several branches:

* **`main` branch** [[**Link**](https://github.com/PathPlanning/TP-SWAP/tree/main)]: Contains README with links.
* **`develop/src` branch** [[**Link**](https://github.com/PathPlanning/Decentralized-Unlabeled-Navigation/tree/develop/src)]: Contains the core implementation of the algorithm.
* **`develop/experiments` branch** [[**Link**](https://github.com/PathPlanning/Decentralized-Unlabeled-Navigation/tree/develop/experiments)]: Includes scripts and resources for running full-scale experiments. This branch provides tools for task generation and experiment execution.
